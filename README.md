# تكاليف الموالح
PWA offline لحساب تكلفة طن الموالح الصافي ظهر الحاوية (كل الأصناف والعبوات).
الحساب (calc / _ld / f) منسوخ حرفيًا من البرنامج الأصلي — ممنوع تعديل طريقة الحساب. أسعار DEF الافتراضية اتحدثت في v2.0.4 من قيم صاحب البرنامج.
اختبار: `node test/calc.test.js && node test/defaults-and-ld.test.js` — بعد تعديل style.css أو index.src.html شغّل `python3 build.py` (بيحط الـ CSS والخط جوه index.html عشان الـ PDF يطلع مظبوط من غير نت).
